# Data and Provenance

## Primary cohort

**GEO accession:** GSE176078

The primary cohort contains 26 breast-cancer samples and 100,064 cells.

The repository does not redistribute the source data.

## TCGA-BRCA

The external cohort is TCGA-BRCA.

The frozen molecular projection used 1,095 expression cases. The independent immune-subtype validation matched 1,083 participants.

## Immune subtype resource

The validation endpoint was the published TCGA immune model-based subtype classification:

`Subtype_Immune_Model_Based`

Represented classes in the matched analysis:

- C1 Wound Healing
- C2 IFN-gamma Dominant
- C3 Inflammatory
- C4 Lymphocyte Depleted
- C6 TGF-beta Dominant

C5 was absent from the matched cohort.

## Data governance

Human genomic data should be obtained directly from the original repositories and handled according to their access and usage requirements.
